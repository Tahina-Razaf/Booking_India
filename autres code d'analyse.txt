
- Pointbiserialr : 
pour l'analyse de correlation entre prix et classe : 
pointbiserialr est un autre méthode pour un groupe binaire

from scipy.stats import pointbiserialr

booking_copy = booking.copy()
booking_copy["class_binary"] = booking_copy["class"].map({"Economy": 0, "Business": 1})

# Si ta variable binaire est bien codée 0/1 ou booléenne
pointbiserialr(booking_copy["class_binary"], booking_copy["price"])

# confirmer avec un test ANOVA
